# Helping Hands – Online Charity Management System

A modern, responsive charity management platform built with HTML5, CSS3, and JavaScript ES6. Fully functional with Local Storage backend.

## Features

✨ **User Features:**
- User registration and authentication
- Donation management system
- Donation history tracking
- User dashboard with statistics
- Campaign browsing and filtering
- Profile management
- Newsletter subscription
- Contact form

🔐 **Admin Features:**
- Complete user management
- Campaign management (CRUD)
- Donation oversight
- Contact message management
- Analytics and reports
- Activity logging
- Statistics dashboard

🎨 **Design Features:**
- Fully responsive design (Mobile, Tablet, Desktop)
- Dark mode toggle
- Modern UI with animations
- Beautiful gradients and effects
- Font Awesome icons
- Google Fonts integration

## Getting Started

1. Open the project in Visual Studio Code
2. Right-click on `index.html`
3. Select "Open with Live Server"
4. The website opens in your browser
